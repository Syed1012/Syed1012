## About

I work across the full stack but go deepest on **distributed backends, cloud-native delivery, and applied AI**. My work spans enterprise identity systems, real-time communication layers, event-driven architectures, and end-to-end AI platforms — always with a focus on building things that are practical, scalable, and production-ready.

I enjoy solving problems where multiple systems need to talk to each other reliably — whether that's orchestrating LLMs with confidence thresholds, setting up multi-database auth flows across global orgs, or wiring up persistent MQTT connections that don't drop.
